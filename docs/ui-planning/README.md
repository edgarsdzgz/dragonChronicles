# UI Planning & Design Reference

## Purpose

This folder contains sketches, mockups, and reference images for UI design planning. These materials are for development reference only and are never used directly in the game.

## Contents

### Sketches

Hand-drawn sketches, wireframes, and concept art for UI elements.

### Mockups

Digital mockups, design iterations, and layout experiments.

### Reference Images

Inspiration images, color palettes, and design references from other sources.

## Organization Guidelines

### File Naming Convention

Use descriptive names with context:

```
[feature]-[element]-[version/variant].ext

Examples:
- journey-controls-sketch-v1.png
- top-bar-layout-mockup-v2.png
- health-bar-color-reference.png
- menu-button-iterations.png
```

### Recommended Folders (create as needed)

```
ui-planning/
├── sketches/           # Hand-drawn sketches and wireframes
├── mockups/            # Digital mockups and prototypes
├── references/         # External reference images
├── iterations/         # Design iteration history
└── archive/            # Outdated/discarded designs
```

## Usage Notes

- **These are planning materials** - Not game assets
- **Keep originals** - Don't delete old iterations, move to archive/
- **Add context** - Include notes about design decisions
- **Reference in docs** - Link to these images from engineering docs when discussing UI implementation
